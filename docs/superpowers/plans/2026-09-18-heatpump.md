# Heat Pump Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task by task.

**Goal:** Deliver the approved card and register its repository as a submodule.
**Architecture:** Separate pure discovery and arithmetic from the HA transport,
then render live controls and statistics with Lit. Browser tests exercise real
custom elements against a fake HA WebSocket and service boundary.
**Tech Stack:** TypeScript, Lit, Rollup, Vitest, Playwright, ESLint.
**Spec:** ../specs/2026-09-18-heatpump-design.md

## Global constraints

- type: custom:heatpump-card; modes all | comfort | water | efficiency.
- cop_window: 24h | 7d | 30d; allow_curve_edit: false by default.
- Default/Bubble appearance, en/nb, registry-first entry isolation.
- Statistics must never divide by zero or treat gaps as zero consumption.
- Committed dist/heatpump-card.js; HACS category plugin only.
